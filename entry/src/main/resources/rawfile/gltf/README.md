# glTF 资源目录

## Phase 0 测试资产

请下载 **DamagedHelmet**（Khronos 官方标准测试模型，CC-BY 4.0，可商用）：

**下载地址：**
https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/DamagedHelmet/glTF

下载后把整个 `DamagedHelmet/` 目录（含 `.gltf`、`.bin`、所有 `.jpg`）放到本目录下，最终结构为：

```
rawfile/gltf/DamagedHelmet/glTF/
  ├── DamagedHelmet.gltf
  ├── DamagedHelmet.bin
  └── Default_*.jpg
```

**快捷下载方式**：
1. 浏览器打开上面地址
2. 点击 `glTF` 文件夹
3. 逐个文件点 Raw → 右键另存（或直接 clone 整个仓库后拷贝）
