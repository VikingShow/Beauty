# 自由布展交互优化方案

## 一、问题诊断

### 1.1 致命 Bug

**SceneSelector 回调未绑定**（第 358 行）
```typescript
// 当前代码 - 缺少回调绑定
SceneSelector({
  selectedSceneId: this.selectedSceneId
})
```
**后果**：用户点击预设场景后，`onSceneSelected` 回调未触发，场景不会加载。应用完全无法使用。

---

### 1.2 交互设计问题

#### 问题 1：模式系统混乱

| 模式 | 触发条件 | 用户感知 |
|-----|---------|---------|
| navigate | 默认/取消选择 | 无提示 |
| place | 导入作品后 | "[放置模式]" 文字 |
| select | 点击作品 | 无提示 |
| transform | **未使用** | - |

**问题**：
- 4 种模式定义，实际只用 3 种
- 用户无法清晰感知当前模式
- `place` 和 `select` 的区别不明确（都是"已选中"状态）

#### 问题 2：作品导入体验差

```typescript
// 当前：作品出现在相机前方 2 米
startPos.x = this.camera.position.x - Math.sin(...) * 2;
startPos.z = this.camera.position.z - Math.cos(...) * 2;
```

**问题**：
- 2 米距离可能在视野外（取决于 FOV 和视角）
- 没有成功提示
- 自动进入 `place` 模式但用户不知道该做什么

#### 问题 3：拖拽移动不符合预期

```typescript
// 当前：移动到 raycast hitPosition
const hitPos = await this.editor.raycastHitPosition(...);
this.editor.moveSelectedToPosition(hitPos);
```

**问题**：
- `raycastHitPosition` 检测**全场景**（地板、墙壁、其他物体）
- 作品会被移动到 hitPosition，可能：
  - 穿透地面（Y < 0）
  - 飘在空中（Y > 作品高度）
  - 卡进墙壁
- 没有**地面平面约束**
- Y 轴高度无法通过拖拽控制

#### 问题 4：属性调整不灵活

当前 PropertyPanel：
- X/Y/Z 位置：固定步长 0.1m
- 旋转：固定步长 15°
- 缩放：固定步长 10%

**问题**：
- 无法精确调整（如移动 0.05m）
- 无法快速大幅调整（如旋转 90°）
- Y 轴标签不直观（应该是"高度"）
- 没有滑块或直接输入

#### 问题 5：相机控制受限

当前：
- Joystick：控制移动（WASD 风格）
- PanGesture：控制视角旋转

**缺失**：
- 双指缩放（pinch to zoom / FOV 调整）
- 视角重置按钮
- 快速传送到作品位置

#### 问题 6：UI 布局问题

| UI 元素 | 位置 | 问题 |
|--------|------|------|
| ArtworkToolbar | 右侧，默认折叠 | 用户不知道有作品列表 |
| PropertyPanel | 底部中央 | 遮挡视线，挡住作品 |
| 右侧按钮列 | 右侧垂直排列 | 太多按钮，拥挤 |
| Joystick | 左下角 | 与 PanGesture 可能冲突 |

**缺失**：
- 操作引导/提示
- 模式指示器
- 快捷键说明

### 2.2 简化模式系统

**从 4 模式简化为 2 模式**：

| 新模式 | 含义 | 行为 |
|-------|------|------|
| `navigate` | 浏览模式 | 相机自由移动，点击作品进入编辑 |
| `edit` | 编辑模式 | 相机锁定，拖拽/调整选中作品 |

**移除**：`place`、`select`、`transform`

**状态指示**：
- 顶部显示当前模式标签
- 编辑模式时，选中作品高亮边框

---

### 2.3 优化作品导入流程

**改进**：
1. 导入后作品出现在**相机视野中央**（计算 FOV 和距离）
2. 显示**成功 Toast**："已导入：{文件名}"
3. 自动进入 `edit` 模式
4. 作品初始 Y = 0（地面）

```typescript
// 计算视野中央前方的位置
const fovRad = this.camera.fov;
const distance = 2.0; // 或根据作品大小动态计算
const forward = this.getCameraForward();
startPos = {
  x: this.camera.position.x + forward.x * distance,
  y: 0, // 地面
  z: this.camera.position.z + forward.z * distance
};
```

---

### 2.4 实现地面约束拖拽

**核心改进**：
1. 拖拽时，只改变 X/Z，**Y 轴固定**（或可选锁定）
2. 使用**地面平面 raycast**（而非场景 raycast）
3. 添加** ghost 预览**（半透明预览位置）

**实现方案**：

```typescript
// GalleryEditor 新增方法
async raycastGroundPlane(screenX: number, screenY: number): Promise<Position3 | null> {
  // 方案 A：使用地面节点的 raycast
  // 方案 B：数学计算射线与 Y=0 平面的交点
  const ray = this.camera.screenPointToRay(screenX, screenY);
  const t = -ray.origin.y / ray.direction.y;
  if (t > 0) {
    return {
      x: ray.origin.x + ray.direction.x * t,
      y: 0, // 固定地面
      z: ray.origin.z + ray.direction.z * t
    };
  }
  return null;
}
```

**拖拽流程**：
1. 用户开始拖拽 → 显示 ghost 预览
2. 拖拽中 → ghost 跟随地面位置
3. 释放 → 作品移动到 ghost 位置

### 2.5 改进属性调整面板

**改进 PropertyPanel**：

1. **添加滑块**（Slider 组件）
   - 位置 X/Z：-50 ~ 50 米
   - 高度 Y：0 ~ 10 米
   - 旋转：0 ~ 360°
   - 缩放：0.1 ~ 5x

2. **添加直接输入**
   - 点击数值 → 弹出输入框

3. **改进标签**
   - Y → "高度"
   - 添加单位提示（m, °, x）

4. **添加快捷按钮**
   - 旋转：45°, 90°, 180°
   - 缩放：0.5x, 1x, 2x
   - 对齐地面

### 2.6 增强相机控制

**添加**：
1. **双指缩放**（PinchGesture）→ 调整 FOV 或距离
2. **视角重置按钮**→ 恢复默认视角
3. **传送到作品**按钮 → 相机移动到作品前方

```typescript
// 添加缩放手势
PinchGesture()
  .onActionUpdate((e: PinchGestureEvent) => {
    const fovDelta = (e.scale - 1) * 30; // 缩放灵敏度
    this.camera.fov = Math.max(30, Math.min(90, this.camera.fov - fovDelta));
  })
```

## 六、总结

当前实现存在**一个致命 Bug**（SceneSelector 回调未绑定）和**多处交互设计问题**。建议按优先级分阶段修复：

**第一阶段（P0-P1）**：修复 Bug + 核心交互改进
**第二阶段（P2）**：UI 优化 + 引导
**第三阶段（P3）**：高级功能

预计工作量：
- P0：0.5 小时
- P1：2 小时
- P2：1.5 小时
- P3：1 小时
- **总计：约 5 小时**
