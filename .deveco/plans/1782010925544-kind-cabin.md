# 实施计划

## 问题 1：首页溢出屏幕

### 解决方案
在 Index.ets 中用 **Scroll** 包裹主内容区域，确保在小屏幕设备上可以滚动查看所有按钮。

**修改**：
```typescript
Scroll() {
  Column({ space: 16 }) {
    // 所有现有内容...
  }
  .width('100%')
  .justifyContent(FlexAlign.Start)
  .padding({ top: 40, bottom: 40 })
}
.width('100%')
.height('100%')
.scrollBar(BarState.Off)
.align(Alignment.Center)
```

## 问题 2：摇杆移出空间

### 解决方案
为每个预设场景添加 **bounds 边界信息**，在加载场景时动态设置相机移动边界。

**修改 GalleryTypes.ets**：
```typescript
export interface PresetScene {
  id: string;
  name: string;
  nameZh: string;
  uri: Resource;
  type: SceneType;
  description: string;
  boundsMin?: { x: number; z: number };  // 新增
  boundsMax?: { x: number; z: number };  // 新增
}

export const PRESET_SCENES: PresetScene[] = [
  {
    id: 'white_cube',
    name: 'White Cube',
    nameZh: '白立方展厅',
    uri: $rawfile('gltf/white_cube/scene.gltf'),
    type: 'gltf',
    description: '简洁白色展厅，9个画位 + 1个雕塑位',
    boundsMin: { x: -4, z: -4 },
    boundsMax: { x: 4, z: 4 }
  },
  {
    id: 'salon_carre',
    name: 'Salon Carré',
    nameZh: '沙龙展厅',
    uri: $rawfile('gltf/salon_carre/scene.gltf'),
    type: 'gltf',
    description: '法式沙龙展厅，22个画位 + 1个雕塑位',
    boundsMin: { x: -9, z: -7 },
    boundsMax: { x: 9, z: 7 }
  },
  {
    id: 'chinese_gallery',
    name: 'Chinese Gallery',
    nameZh: '中国馆',
    uri: $rawfile('gltf/chinese_gallery/scene.gltf'),
    type: 'gltf',
    description: '中式三厅，12幅传世名画',

    boundsMax: { x: 15, z: 10 }
  },
  {
    id: 'david',
    name: 'David Gallery',
    nameZh: '大卫馆',
    uri: $rawfile('gltf/David/scene.gltf'),
    type: 'gltf',
    description: '文艺复兴艺术馆，18幅名画',
    boundsMin: { x: -20, z: -15 },
    boundsMax: { x: 20, z: 15 }
  }

```

**修改 UserGalleryPage.ets**：
```typescript
private async onSceneSelected(uri: Resource | string, type: SceneType, id: string): Promise<void> {
  this.selectedSceneId = id;
  // ...
  
  // 根据场景设置边界
  const sceneConfig = PRESET_SCENES.find(s => s.id === id);
  if (sceneConfig !== undefined && 
      sceneConfig.boundsMin !== undefined && 
      sceneConfig.boundsMax !== undefined) {
    this.controller.setBounds(sceneConfig.boundsMin, sceneConfig.boundsMax);
  } else {
    // 默认边界
    this.controller.setBounds({ x: -20, z: -20 }, { x: 20, z: 20 });
  }
}
```

## 问题 3：测试用的 GLB 资源

### 在线 GLB 资源推荐

以下网站提供免费 GLB 模型下载：

| 网站 | 说明 | 许可证 |
|-----|------|--------|
| **[Sketchfab](https://sketchfab.com/feed)** | 最大 3D 模型平台，搜索 "free download glb" | 多数 CC |
| **[Poly Pizza](https://poly.pizza/)** | 免费 GLB 模型库，适合测试 | CC BY |
| **[Kenney Assets](https://kenney.nl/assets)** | 游戏素材包，含家具/道具 | CC0 |
| **[Quaternius](https://quaternius.com/)** | 低多边形模型，体积小 | CC0 |

### 推荐测试模型

**雕塑/艺术品**：
- [David Statue](https://sketchfab.com/3d-models/david-michelangelo-870b6e36e5874d7fa26c8a5c4e5e5e5e) — 经典雕塑
- [Venus de Milo](https://sketchfab.com/search?q=venus+de+milo&type=models) — 希腊雕塑

**家具**：
- [Sofa](https://poly.pizza/m/sofa-low-poly) — 沙发
- [Table](https://poly.pizza/m/table-low-poly) — 桌子
- [Pedestal](https://sketchfab.com/search?q=pedestal&type=models) — 展台

**画框**：
- [Picture Frame](https://sketchfab.com/search?q=picture+frame&type=models) — 画框

### 使用方法
1. 从上述网站下载 GLB 文件
2. 在"自由布展"页面点击"添加作品 (.glb)"
3. 选择下载的 GLB 文件
4. 作品将自动出现在视野中央
