# 中国馆建筑设计图纸 v2 — 轴系修正版

## 坐标系（与 David 模型一致）

```
        北 (Z−)
         ↑
         │
  西 ←───┼───→ 东 (X+)
  (X−)   │
         ↓
        南 (Z+)
```

| 轴 | 方向 | 说明 |
|----|------|------|
| X+ | 东 | 左手边 |
| X− | 西 | 右手边 |
| Y+ | 上 | 标高 |
| Z+ | 南 | 建筑正面朝向 |
| Z− | 北 | 建筑背面 |
