# 艺树（ArTree）—— 让每一幅画都成为一个世界

> **平台**：HarmonyOS 6.0+
> **作品形态**：鸿蒙原生 3D 艺术馆应用（Demo）
> **目标版本**：HarmonyOS 6.0 / 7.0 beta

---

## 一、项目概述

### 1.1 我们做什么

**艺树（ArTree）** 是一个基于 HarmonyOS ArkGraphics 3D 的沉浸式线上艺术馆平台。用户以第一人称视角在 3D 展厅中自由漫游，走近画作时会触发 AI 语音深度讲解；每幅画都包含一个可"走入"的微型 3D 世界（画中世界），将平面的艺术欣赏拓展为空间化的沉浸体验。

同时，艺树内置了基于真实艺术史悬案的解谜推理系统——以 1934 年根特祭坛画《公正法官》面板失窃事件为蓝本，玩家需要在 18 幅名画中收集线索、推理锁定藏匿画作——让艺术学习变成一场侦探游戏。

### 1.2 我们要解决的问题

| 痛点 | 艺树的解法 |
|------|-----------|
| 美术馆资源集中线下，地域/时间/成本门槛高 | 3D 线上展厅，随时随地"走进"美术馆 |
| 传统观展走马观花，缺乏深度互动 | AI 语音导览 + 画中世界沉浸 + 解谜驱动探索 |
| 新兴艺术家缺乏展示渠道和收入来源 | 支持上传作品/场景模型 + 虚拟门票商业闭环（规划中） |
| 公众对艺术史感到枯燥、距离感强 | 以真实艺术史悬案为剧本，将学术知识转化为游戏叙事 |

## 二、创新场景设计

### 2.1 核心创新点

**① 画中世界（Painting World）—— 从"看画"到"入画"**

走近一幅画作后，点击"走入画中"即可进入画作内部的 3D 微缩世界。每幅画拥有独特的配色、地形和氛围：蒙娜丽莎的托斯卡纳丘陵、莫奈日出的勒阿弗尔港晨雾、弗里德里希的云海山巅……基于深度估计算法，从 2D 画作中生成 3D 浮雕地形，让观者真正"走入"艺术家的视角。

**② 侦探解谜式艺术学习**

以真实艺术史悬案——1934 年根特祭坛画《公正法官》面板失窃事件——为主线的推理解谜系统。18 幅画作中散布 6 条"窃语"线索，每条线索都是一次艺术史知识的学习（如"十五世纪"、"弗拉芒油画技法"、"西西里画派"），集齐线索后通过逻辑推理锁定目标画作。将枯燥的艺术史知识转化为沉浸式侦探体验。

**③ 双馆叙事架构**

"西洋馆"与"中国馆"并列，不将东西方艺术对立，而是让观者在两个空间中自由穿行，感受不同文明对"美"的共同追求。中国馆以"兰亭序之谜"为叙事核心，12 幅传世名画等待探索。

**④ AI 语音深度导览**

基于鸿蒙 Core Speech Kit，每幅画有专属 AI 语音旁白。不是简单朗读画名和年代，而是讲述这幅画背后的故事、技法创新和人文内涵。字幕与语音同步，支持静音模式。

### 2.2 与同类产品的差异

| 对比维度 | 传统线上画展（网页/VR） | Google Arts & Culture | 艺树（ArTree） |
|---------|----------------------|----------------------|---------------|
| 交互方式 | 点击翻页/360°全景 | 缩放浏览 | 第一人称自由漫游 |
| 深度理解 | 文字说明 | 文字+短视频 | AI语音+画中世界+解谜 |
| 创作参与 | 无 | 无 | 支持上传作品/场景 |
| 商业模式 | 免费 | 免费 | 虚拟门票+艺术家分成 |
| 平台 | Web/VR头显 | Web/App | 鸿蒙原生（全场景协同） |

## 三、用户与市场分析

### 3.1 核心用户

- **艺术爱好者**（18-45 岁）：希望深入了解艺术但缺乏线下观展条件
- **学生群体**：需要生动有趣的艺术史学习方式
- **新兴艺术家**：缺少展示空间和变现渠道
- **策展人/画廊**：需要低成本的线上展览解决方案

### 3.2 市场潜力

- 全球线上艺术市场 2024 年规模约 **118 亿美元**（Statista），预计 2030 年达 **250 亿美元**
- 中国数字艺术消费用户已超过 **3 亿**（QuestMobile 2025）
- 线下美术馆单次特展成本通常在 **50-500 万元**，而线上 3D 展厅的建设成本仅为其 1%-5%
- 鸿蒙生态设备已超过 **10 亿台**，覆盖手机、平板、智慧屏、车机等多种终端
- "线上观展 + 数字门票"模式已被大英博物馆、卢浮宫验证（疫情期间线上收入增长 300%+）

### 3.3 商业闭环（规划中）

```
艺术家上传作品 → 3D 展厅自动生成 → 观众购买虚拟门票
                    ↓
              平台抽成 15-30%
                    ↓
              艺术家获得门票收入 + 曝光
                    ↓
              优质展览 → 更多观众 → 正循环
```

## 四、HarmonyOS 技术集成方案

### 4.1 使用的鸿蒙开放能力

| 能力 | 用途 | 创新主题 |
|------|------|---------|
| **ArkGraphics 3D** | 3D 展厅渲染、PBR 材质、实时光影、第一人称相机 | 3D 空间化 |
| **Core Speech Kit** | AI 语音旁白（TTS 文本转语音），支持中文/多语言 | AI 智能化体验 |
| **ArkUI** | 模糊透明美学 UI、毛玻璃模态、矢量小地图、虚拟摇杆 | UX 美学 |
| **ArkWeb** | Three.js 画中世界渲染、WebView 嵌入 3D 微缩场景 | 3D 空间化 |
| **Media Kit** | 文艺复兴背景音乐播放（AVPlayer 循环） | 沉浸体验 |
| **AVSession / Audio Kit** | 语音旁白与背景音乐的音频焦点管理 | 体验优化 |
| **文件管理 / 沙箱** | 用户上传作品的安全隔离存储 | 安全隐私保护 |
| **HarmonyOS Account Kit** | 艺术家身份认证 | 安全隐私保护 |
| **Distributed Data / 分布式流转** | 多设备协同观展（手机扫码→平板/智慧屏接力） | 全场景一体协同 |
| **Core Vision Kit** | 画作图像识别 → 自动生成标签和介绍 | AI 智能化体验 |

### 4.2 核心技术实现

**3D 渲染管线**
```
glTF 2.0 场景模型（离线生成）
    → ArkGraphics 3D Scene.load()
    → PBR 材质 + 4 方向光照（主光/冷补光/暖侧光/天顶光）
    → Component3D 组件嵌入 ArkUI 布局
    → 60fps 实时渲染
```

**画中世界生成**
```
2D 画作纹理 → 深度估计模型（离线 Python）
    → 64×64 深度图 → 顶点位移生成 3D 浮雕地形
    → glTF 数据内嵌 WebView → Three.js 渲染
    → 重力 + 跳跃物理 + 地面碰撞
```

**AI 语音管线**
```
遇到画作 → 触发 speak(title + description)
    → Core Speech Kit TTS Engine（person:0, rate:0.85, pitch:0.9）
    → 字幕回调 → ArkUI Text 组件实时显示
    → 静音模式：只显示字幕，不播放声音
```

**解谜推理引擎**
```
收集线索 → 排除画作（按艺术史分类：年代/画科/尺寸/画派/地理）
    → 候选集逐步缩小（18→5→2→1）
    → 集齐 6 条 → 唯一锁定目标画作
```

## 五、安全隐私保护方案（创新主题覆盖）

### 5.1 用户数据保护

- 艺术家上传的作品存储于鸿蒙应用沙箱，外部应用无法访问
- 用户观展记录仅保存在本地，不上传服务器（除非用户主动选择云端同步）
- 虚拟门票交易通过 HarmonyOS IAP Kit 完成，不接触用户支付信息

### 5.2 内容安全

- 上传作品经 Core Vision Kit 自动审核（色情/暴力/政治敏感内容识别）
- 展览内容可由策展人设置访问权限（公开/仅门票持有者/仅受邀者）
- 数字水印嵌入上传作品，防止未经授权的二次传播

## 六、全场景协同方案（创新主题覆盖）

### 6.1 多设备观展体验

```
手机扫码进入展览 → 走近画作 → 轻触"投屏"
    → 平板/智慧屏自动接续，展示高清画作细节
    → 手机变为语音导览遥控器 + 字幕显示
    → 手表同步震动提醒"前方有隐藏线索"
```

### 6.2 分布式画廊

- 多个用户同时进入同一展厅，看到彼此的位置和视角（虚拟化身）
- 策展人在平板上布置展览，观者在手机上实时看到变化
- 基于鸿蒙分布式软总线，设备间延迟 < 20ms

### 7.1 可开源组件

| 组件 | 说明 | 许可证 |
|------|------|--------|
| `glTF Scene Generator` | Python 程序化 3D 展厅生成器 | Apache 2.0 |
| `Painting World Builder` | 2D→3D 画中世界生成管线 | Apache 2.0 |

### 7.2 开源场景化能力

- **程序化展厅生成**：输入画作列表 + 布局参数，Python 脚本自动生成 glTF 2.0 场景文件
- **画作纹理管线**：批量从 Wikimedia Commons 下载公有领域画作 → 压缩 → 嵌入 glTF
- **深度估计→浮雕地形**：基于深度学习的单目深度估计，将任意 2D 画作转为 3D 地形

## 十、社会价值

**艺树（ArTree）** 的使命不是替代线下美术馆，而是让那些因为地理距离、经济条件或身体限制而无法亲临美术馆的人，也能走进艺术的殿堂。

我们相信：**艺术不应有门槛，美应该在每一个人触手可及的地方。**

通过技术手段降低艺术教育的成本、通过商业模式支持艺术家的创作、通过沉浸式体验让更多人爱上艺术——这就是艺树存在的意义。
